## 🎓 uTest Academy là gì?

uTest Academy là chương trình đào tạo của uTest/Applause, gồm các **practice test cycles** (cycle thực hành, không có payout) giúp tester trải nghiệm đúng quy trình một cycle trả phí thật: test, report bug, hoàn thành test case, nhận feedback.

**EN:** uTest Academy practice cycles are training-only (no payouts). To pass each cycle you need **at least 1 approved bug report + 1 approved test case**.

## 🗺️ 6 practice test cycles

| # | Cycle | Cách tham gia | Trạng thái của anh |
|---|-------|---------------|--------------------|
| 1 | **Introduction to Testing** (Under Armour VN — cycle #563984) | Sign up sau khi pass quiz | 🟢 **ĐANG TEST** (deadline 06/11/2026 09:00) |
| 2 | Computer Testing | Phải pass cycle 1 | ⚪ Chưa mở |
| 3 | Mobile Device Testing | Phải pass cycle 2 | ⚪ Chưa mở |
| 4 | Charles Proxy Testing | Phải pass cycle 3 | ⚪ Chưa mở |
| 5 | Academy Challenge | Phải pass cycle 4 | ⚪ Chưa mở |
| 6 | Academy All Stars | **Chỉ được mời** (phải pass cả 5 cycle trước + report chất lượng cao) | ⚪ Chưa mở |

## 💰 Lợi ích tham gia Academy

- Trải nghiệm đúng quy trình một test cycle thật của uTest
- Áp dụng kiến thức từ các khóa Academy: testing, report bug, test case, review
- Được Academy team feedback và góp ý cải thiện kỹ năng
- **Work được approve sẽ nâng tester rating dần dần → rating cao = nhiều cơ hội nhận cycle trả phí hơn**
